## Optimization exclusions require evidence

`bc0aa059` adds Cython CAN parsing/packing and radar scalar/motion kernels; Rust already has native `can` and `radarcan`/`radard` implementations, so Python backend loaders and Cython build plumbing need not be recreated. This is structural redundancy only. Source's golden parser/packer output, NaN/ordering/cadence semantics and radar update traces must still be compared. No measured performance or full semantic equivalence is claimed here.

`021594e9`, `86d1e215`, `0611d489` add changed-input cost/cache work. Rust `plannerd/src/longitudinal_mpc/cost.rs` currently writes every stage/slack on each `set_weights`; lateral MPC has no demonstrated unchanged-cost cache. Therefore native language alone is insufficient evidence to omit these optimizations. Add equivalent caches with solver-reset invalidation or document measured no-benefit and semantic parity. Current fixed arrays, scoped native parser state and radar path cache can be retained; do not overwrite custom native fixes by copying Python architecture.

## Scale, ordering and limits

The controls/car/monitoring/selfdrived source delta alone contains 67 files, +7,306/-169 lines including tests. Radar/vehicle additions substantially exceed that: Bosch implementation ~7.3k lines, ARS510 ~2k, plus large Hyundai regression suites. This is multiple functional ports, not a source sync or small optimization patch.

Recommended implementation order: (1) schema/Params/topic inventory and final-source test vectors, (2) DM2 + lateral/impact safety boundaries, (3) Toyota/Hyundai controllers and safety companion, (4) Bosch/ARS radar decoders, (5) final radar selection/advisory and comfort/MPC/planner rules, (6) event/HUD/UI wiring and changed-input optimizations. Signal integration and blindspot metadata need parallel owner coordination. Finish each group with deterministic source-differential traces and Rust regression fixtures before integrated startup/record/upload validation. No audit finding permits weakening thresholds, overriding custom native fixes, changing dev/main, pushing or touching vehicles.
