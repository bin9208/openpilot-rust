- 요청: 사용 중에는 컴파일 → 빌드 완료 → 화면·부팅 → 실제 기능 정상 동작으로 수용한다.
- 추적: https://github.com/bin9208/openpilot-rust/issues/689
- 기반: #681의 `6941685b331c9c60c391432efd8e1104076388d8`. 다른 세션의 작업 디렉터리와 실물에는 접근하지 않는다.
- 작업 브랜치: `codex/fix-689-user-startup`. `dev-md` runtime을 `dev`에 합치지 않는다.

## 변경

일반 `source_entry.py --launch`는 개발용 세대 생성 경로와 분리한다. 빌드 전에
기존 spinner와 독립 6999 복구 서버를 시작한다. 기존 Rust 실행 파일이 없으면 원본
Python UI·독립 복구 서버를 사용한다. 컴파일 실패 시 원본 오류 화면과 로그 경로를
표시하고 복구 서버를 유지한다. 실제 표시·기기 포트 접속 성공은 아직 미확인이다.

준비된 build plan과 provider를 사용하여 Cargo를 실행하고 변경된 실행 파일과 필수
데이터만 설치한다. 일반 컴파일에서는 `Prepared::verify`, 세대 `seal`, 전체 SDK/tree
재검사, ELF/ABI 감사, 산출물 object 보관을 호출하지 않는다. 감사용 실행 파일도
일반 runtime 컴파일 대상에서 제외한다. 명시적인 `--verify-package`와 개발용 세대
검사는 유지한다. 기동 중 모델·OS 호환성 및 차량 런타임 유효성 정책은 그대로 적용한다.

기존 고정 `build-workspace`와 성공 빌드 기록의 Cargo target 경로를 재사용한다.
성공 기록은 캐시 경로 힌트이며 현재 빌드 통과의 증거로 계산하지 않는다. 실제 변경
판정은 Cargo가 한다. 이전 패키지를 가리키는 `rust/bin`은 새 컴파일이 모두 성공한 뒤
단일 `.source-bin` 디렉터리로 전환한다. 빌드 실패로 이전 실행 파일을 덮어쓰지 않는다.
변경 없는 HEAD·파일 메타데이터에서는 입력 준비와 Cargo를 생략한다.

입력 정의가 같으면 기존 입력 준비 결과의 경로·recipe를 재사용하며 SDK/model tree를
다시 열어 검증하지 않는다. helper가 바뀌면 현재 소스 helper를 준비한다. 사용 가능한
준비 결과가 없는 최초 설치나 의존성 변경 시 기존 다운로드·입력 준비가 필요하다.
**그 초기 준비 내부의 기존 seed/helper 감사는 이번 변경만으로 전부 제거되지 않는다.**
초기 설치 시간을 10~20분으로 달성했다고 보고하지 않는다. 이 경로의 추가 단축은
실기에서 초기 준비와 순수 컴파일 시간을 분리한 결과에 따라 이어간다.

일반 updater는 배포 패키지 준비를 호출하지 않고 Git 소스를 준비한다. 업데이트된
checkout은 다음 시작에서 같은 변경분 빌드 경로로 들어간다. 컴파일을 60초짜리 manager
잠금 인계 대기 안에 넣지 않는다. 빌드별 메모리 cap은 현재 커널 가용 메모리에 맞춘다. 디스크·메모리 보호는 커널
카운터로 유지하며 SDK/산출물 내용을 다시 읽지 않는다. 자원 기록은 최신 한 파일로
교체하며 커밋마다 패키지나 세대를 보관하지 않는다. 이전 `build.json`이 있어도 일반
소스 빌드는 현재 Git 버전을 UI/업데이트 메타데이터로 사용한다.

## 검사와 수용

로컬에서는 변경 파일 문법·rustfmt·diff만 확인한다. GitHub Actions의 짧은 x86 검사로
실제 작은 프로그램의 최초 컴파일, 무변경 재사용, 변경분 컴파일·실행, 실패 시 이전
실행 파일 보존을 확인한다. spinner/복구 시작 순서와 무변경 시 준비·컴파일 생략도
집중 검사한다. 전체 workspace/ARM/AGNOS 감사는 자동으로 실행하지 않는다.

현재 실기 수용은 **대기**다. 해당 HEAD를 수정 브랜치에서 사용자가 설치하여 최초/수정
빌드 시간, 진행 화면, 빌드 도중·실패 시 6999, 정상 부팅 및 모든 기능의 동작을 확인해야
한다. 호스트 검사 통과로 이 조건을 대신하지 않으며 그 전에는 #689를 닫거나 최종 병합하지 않는다.
