# 모든 브랜치 CI 작업 정리 (#644)

2026-10-30 사용자가 Fast checks와 불필요한 작업을 모든 브랜치에서 제거하도록 지시했다.
171개 원격 브랜치 전체를 조사했다. 별도 Fast checks 및 통합 CI fast-checks job,
일회성 once workflow, 완료된 환경·용량 진단, 원본 포크 전용 동기화·발행을 제거한다.
일회성 진단에 딸린 보조 파일도 제거하며 Git/Actions 과거 이력은 유지한다.

Rust/통합 CI는 기능 브랜치의 중복 push를 없애고 PR 검증과 dev/dev-md/main 통합 후
검증을 유지한다. 빌드·기능·ARM/AGNOS 검증, 좁은 경로의 네이티브 캐시 검증은 유지한다.
dev-md 차단과 Xiaoge 원본 입력 검증은 실제 소유 job으로 옮긴다. 삭제한 Fast checks는
보호 브랜치 필수 검사 및 네이티브 입력/런타임 발행 조건에서도 제거한다.

브랜치마다 기존 tip을 부모로 하는 CI 정리 커밋을 만든다. 브랜치 간 소스 병합, 강제 push,
다른 세션의 체크아웃·미커밋 파일 변경은 하지 않는다. 정리 커밋은 [skip ci]로 기능 검증을
대량 중복 실행하지 않으며 이미 실행 중인 검사도 취소하거나 재시작하지 않는다.
로컬 확인 범위는 YAML/Python/Rust 구문·서식, diff, job 의존 관계와 기능 명령 보존이다.
기능 실행 성공이나 실기기 검증 완료로 표현하지 않는다.

정확한 각 브랜치 이전/이후 SHA와 저장소 설정 readback은
[이슈 #644](https://github.com/bin9208/openpilot-rust/issues/644)에 기록한다.
