## Signal interface

Final planner consumes `prepare_decision.active`, `prepare_control_active`, `start_decision.hold`, `signal_detection_suspended`, `signal_observation_color`, and `signal_green_active`. Prepare acceleration uses monotonic elapsed time (initial model dt), previous published acceleration (initial ego acceleration), driver/reset/stop/ACC/primary-lead vetoes, and clears coasting. A start hold forces shouldStop, zero target velocity and nonpositive acceleration. Publication action precedence is hold1, prepare2, green3, otherwise0. These hooks must use the final signal decision producer; defaults alone do not complete signal functionality.

### Active-signal producer contract for integration owner

The exact final planner consumes `prepare_decision.active`, `prepare_control_active`, `start_decision.hold`, `signal_detection_suspended`, `signal_observation_color`, and `signal_green_active` from Carrot. Consumer order is coasting, then PrepareAccel, then start hold. Prepare activates only with both prepare flags, no reset/pedals/shouldStop, ACC mode, no leadOne/leadTwo and elapsed in `(0,.2]`; it clears coasting, caps speed/desired acceleration and tightens jerk only when the acceleration cap binds. First previous acceleration is measured aEgo, then the preceding final acceleration. Inactive/invalid cap resets its memory. Start hold sets shouldStop, speed0 and acceleration min(existing,0), retaining stronger braking. Publication action priority is hold1, prepare2, green3, otherwise0. Active producer/consumer/full publication equivalence remains an integration gate, not covered by the explicitly inactive 1,080-frame oracle.
