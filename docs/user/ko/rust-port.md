# 실험용 Rust 포팅

이 독립 저장소는 프로젝트 소유 Rust 런타임 후보와 소스에 맞는 AGNOS 설치 경로를 제공합니다.
전체 소스 전환과 기기·차량별 수용은 #1/#296에서 별도로 추적합니다. 일반 호스트나
범용 ARM 빌드 대신 설치할 소스와 정확히 일치하는 검증된 AGNOS 릴리스를 사용합니다.

Rust 1.94.0이 설치된 Linux 개발 호스트에서 `rust/` 디렉터리로 이동해 실행합니다.

```sh
cargo run --release --locked --bin cpu-sample -- 1000
```

선택 인자는 측정 간격이며 1~60000밀리초, 기본값은 1000입니다. TSV로 출력합니다.
100%는 논리 코어 하나 기준이므로 멀티스레드 프로세스는 100%를 넘을 수 있습니다.
processor 열은 마지막으로 관찰된 메인 스레드의 코어이며, 프로세스 affinity나 모든
스레드의 배치가 아닙니다. 읽을 수 없거나 종료된 프로세스와 유효하지 않은 카운터
차이는 제외합니다. 짧은 측정 간격에서는 시간 카운터의 해상도 한계가 큽니다.

이 도구는 한 번 측정하는 진단 도구이며 상주 서비스가 아닙니다. 차량 명령을 발행하지
않습니다. 호스트 테스트와 일반 aarch64 빌드 성공은 AGNOS 호환성, CPU 절감, 온도 개선,
차량 안전 검증을 뜻하지 않습니다. 일반 CI 빌드를 차량에 설치하지 마세요. 대상 기기
검증은 아직 남아 있습니다.

## 오래된 결함의 후속 수정 후보

2026-10-23의 #497 작업 브랜치는 다음 교정을 검증 중입니다. 기존 공개 릴리스에
모두 반영됐다는 뜻은 아니며 실제 설치·주행 수용은 별도입니다.

- 토크 DEBUG 점 목록이 메시지 용량을 넘으면 해당 목록만 생략하고 진단을 남깁니다.
- 업로더가 건너뛸 파일의 완료 표시를 쓰지 못하면 실패를 기록하고 재시도합니다.
- PC에서는 업로더가 원본과 같이 CPU 배치를 변경하지 않습니다. 기기의 기존 0..3 코어 정책은 유지합니다.
- raw 영상 쓰기·flush·close 실패는 미완료 표시를 유지하고 오류를 보고합니다.
- 카메라 서버가 바뀌면 인코더가 다시 연결합니다. 버퍼 구조가 달라지면 안전한 재시작을 요구합니다.
- 외부 Jetlink 프레임은 원시 예측 텐서를 제공하지 않습니다. `SEND_RAW_PRED`가 켜져도
  정상 외부 프레임 발행을 계속하고 해당 원시 필드는 비웁니다. 내부 모델의 원시 출력은 유지합니다.
- Dashcam 보고서의 번호형 운전자 경고와 실시간 내비게이션 안내 표시를 바로잡습니다.
- 현대 CANFD 대체 버튼, Tesla 취소 이벤트, Volkswagen MQB의 초기 상태 처리 교정을
  별도로 검증합니다. 자료가 없는 차량의 토크 설정이나 DBC를 임의로 대체하지 않습니다.
- 터미널 초기화와 종료 시 해당 세션이 소유한 작업도 정리합니다.

이 수정은 CPU 절감이나 모든 차량의 정상 동작을 입증하지 않습니다. 모델 불확실성을
이용한 횡방향 평활화 교정은 기존 보간 범위·상한을 유지하며 별도 차량 수용이 필요합니다.

감사 수정 후보는 정확한 원본 wheel-speed helper와 DBC로 기존 PSA dashcam 매개변수·상태·제어 경로를 복구합니다. PSA의 `dashcamOnly`, 각도 제어, 3개 CAN 버스와 기존 20 Hz 조향·상태 주기는 유지하며 실물 CAN 수용은 대기 중입니다. controlsd의 과거 DBC 누락 시작 거부도 제거하고 실제 PSA 각도 매개변수와 기존 정상 튜닝 반례를 비교하며, Actions 검증은 대기 중입니다. K5 Hybrid 2024 토크 키 교정은 기존 포크 행을 그대로 사용하는 명시적 추론 별칭이며, 독립적인 보정값 검증이나 실차 수용을 뜻하지 않습니다.
